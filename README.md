# 红中麻将 · 好友牌桌

用浏览器创建房间，把邀请链接发给牌友。牌友也可以在首页输入同一个六位房间码。四位真人入座后自动开局。房主也可以添加或移除人机，四个座位齐备后点击“开始对局”。真人在开局前可以接替人机座位。

## 本机启动

需要 Node.js 22 或更新版本。解压后，Windows 可双击 `start-windows.cmd`。也可以在项目目录运行以下命令。

```sh
node server.mjs
```

用浏览器打开 `http://127.0.0.1:3000`。单机测试四个真人席位时，请使用四个独立的浏览器配置文件，因为同一配置文件会记住自己在该房间的座位。手机推荐横屏。

## 不租服务器的好友联机

### 同一 Wi-Fi 或局域网

1. Windows 房主双击 `start-lan.cmd`。也可以运行 `node host.mjs --lan`。
2. 房主和牌友都用浏览器打开窗口里对应同一网络的「同网牌友入口」，例如 `http://192.168.1.20:3000`。房主创建房间后发邀请链接，或让牌友在同一网站输入房间码。
3. 保持房主电脑和启动窗口运行。如果 Windows 提示防火墙访问权限，按实际使用的可信网络设置放行。请确认设备在同一网络，使用访客 Wi-Fi 时留意设备之间是否允许互通。

### 异地联机，牌友只用浏览器

1. 只有房主需要从 [Cloudflare 官方下载 cloudflared](https://developers.cloudflare.com/tunnel/downloads/)。Windows 可将对应架构的文件命名为 `cloudflared.exe`，放在游戏目录，或把它加入 `PATH`。
2. 双击 `start-online.cmd`，或运行 `node host.mjs --online`。窗口显示「异地牌友入口」后，房主打开网页建房，再复制邀请链接。房主从同一窗口提示的本机入口建房时，邀请按钮也会使用生成的公网地址。
3. 牌友在浏览器打开邀请链接即可入座。保持房主电脑和启动窗口运行。临时隧道重启后可能会更换网址，换网址后请分享新的邀请并重新开桌。

这是免租服务器的临时试玩方式。Cloudflare 快速隧道无需账号或域名，能否连上取决于房主和牌友所在的网络。可以先让一位牌友打开链接测试。 [Cloudflare 快速隧道说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

如果牌友已经在同一个 Tailscale 私有网络，也可以用 `start-lan.cmd`，再打开窗口提示的 Tailscale 地址。Tailscale 个人免费计划最多支持 6 个用户。 [Tailscale 免费计划](https://tailscale.com/docs/account/manage-plans/free-plans-discounts)

### 使用已有的服务器或反向代理

服务器运行一个 Node 进程，前端页面和游戏接口都由该进程提供。可以把 HTTPS 交给反向代理，并转发请求到本机 `127.0.0.1:3000`。如果反向代理会改写 `Host`，设置 `HONGZHONG_INVITE_ORIGIN` 为牌友访问的完整源地址，例如 `https://game.example.com`。

- 默认监听本机地址。托管环境要求监听所有接口时，设置 `HOST=0.0.0.0`。可以用 `PORT` 修改默认端口。
- 本机、局域网和公网隧道默认分别保存到 `data/`、`data-lan/` 和 `data-online/`。可以用 `HONGZHONG_DATA_DIR` 指定持久可写目录。无人在线且超过 24 小时没有牌局变动的房间会清理。
- `GET /healthz` 可检查服务状态。邀请链接默认使用当前访问地址。本机入口优先使用启动器给出的共享地址（如已配置）。

## 规则和操作

- 112 张牌，红中能补顺子、刻子和将牌。四组牌加一对将可胡，四红中也可直接胡。可碰、杠。含红中只能自摸，无红中也可接炮。
- 每人起始 400 枚虚拟筹码。暗杠当场向三家各收 10 枚。每次点杠或补杠记 1 番花，胡牌时兑现。每张红中和杠开各加 1 番。胡牌每份为 10 枚乘以 2 的番数次方，按自摸或点炮结付。
- 新摸的牌单独放在最右边，与手牌隔一张牌。默认按万、筒、条和点数整理其余手牌，红中放在普通牌后。可用鼠标或触屏拖动手牌，也可用 Alt 加左右方向键换位。
- 鼠标悬停在手牌上会高亮桌面的同牌。轮到自己时，悬停还可以预览打出这张牌后的听牌和余量。已听牌时，点屏幕右侧的“听”查看能胡的牌。余量扣除自己已知的牌和桌上的弃牌、明碰、明杠。
- 先点选手牌，再点“打出”。出牌限时 24 秒，碰、杠、胡的回应限时 8 秒。超时默认代打或过牌。同一张弃牌有两家或三家点胡时，各家都算胡，放炮者按各家番数分别赔付。筹码不足时按应付筹码的比例分配余额。
- 点牌桌底栏的“声音”，可以调节背景音乐音量，分别开关背景音乐、牌桌音效和普通话配音，并试听碰、杠、胡。背景音乐和音效随游戏提供，配音使用设备或浏览器提供的普通话语音。
- 庄家自摸连庄。闲家自摸或一家接炮时，由胡牌的人接庄。两家或三家接炮时由放炮者接庄。流局由庄家的下家接庄。结算会显示下一局的庄家。
- 本桌余额跨局保留。牌墙摸空判流局，已付的暗杠筹码保留。每局后四个席位在线时可继续下一局，有人筹码归零则结束该桌。
